# CPU-Process-and-Task-Scheduling-Simulator

## Overview

The **CPU Process and Task Scheduling Simulator** is a Data Structures and Algorithms (DSA) mini-project developed using C++. It aims to simulate CPU scheduling in an operating system and compare the performance of different scheduling algorithms.

## Objectives

- Implement different CPU scheduling algorithms.
- Calculate completion time, turnaround time, and waiting time for each process.
- Display the execution order of processes.
- Compare scheduling algorithms using the same input workload.
- Analyze the effect of time quantum on Round Robin scheduling.

## Algorithms to Be Implemented

1. **First-Come First-Served (FCFS)**
2. **Round Robin (RR)** using a circular queue.
3. **Priority Scheduling**

## Planned Features

- Store process ID, arrival time, burst time, and priority.
- Display the execution order of processes.
- Calculate completion time, turnaround time, and waiting time.
- Compare the performance of scheduling algorithms.
- Analyze the effect of different time quantum values on Round Robin waiting time and context-switch frequency.
- Define rules for handling ties between processes.
